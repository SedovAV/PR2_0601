## Решение задачи бинарной классификации (на примере предсказания оттока клиентов)

### Цель работы

Освоить полный цикл решения задачи бинарной классификации: разведочный анализ данных, предобработку, обучение моделей, оценку качества и интерпретацию результатов

### 1. Теоретическая справка

<b>Бинарная классификация</b> — задача отнесения объекта к одному из двух классов (0/1, «да»/«нет»).

Примеры в бизнесе:

* отток клиента (churn) — уйдёт / останется;
* кредитный скоринг — вернёт долг / допустит дефолт;
* фрод-детекция — мошенническая операция / легитимная;
* отклик на маркетинговую кампанию.

### 2. Постановка задачи

<b>Задача</b>: телеком-компания хочет заранее выявлять клиентов, склонных к оттоку, чтобы удержать их с помощью персональных предложений.

<b>ML-задача</b>: построить модель, которая по характеристикам клиента предсказывает вероятность оттока (`Churn = 1`).

<b>Критерий</b>: ROC-AUC ≥ 0.80 и Recall ≥ 0.70 при Precision ≥ 0.50 (бизнесу важнее не пропустить уходящего клиента).

### СПРАВКА

* <b>Гиперпараметр в машинном обучении</b> — это настройка модели, которая задаётся до начала процесса обучения и не изменяется в ходе обучения. В отличие от параметров модели (например, весов нейронов в нейросетях), которые модель автоматически настраивает на основе данных, гиперпараметры определяют архитектуру модели и стратегию её обучения
